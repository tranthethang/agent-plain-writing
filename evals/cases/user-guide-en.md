# SIMULATED DATA

## Audience

New store clerks who use the KoraPOS tablet app to export daily sales reports.

## Brief

### Feature
Export a daily sales summary as a CSV file from KoraPOS on an iPad or Android tablet.

### Steps
1. Open **KoraPOS** and tap **Reports** in the bottom bar.
2. Select **Daily Sales** and pick one date from the calendar (up to 90 days back).
3. Tap **Export CSV**, then choose **Save to Files** or **Send to Email**.
4. Wait up to 15 seconds for the file `sales-YYYY-MM-DD.csv` to appear.

### Reader
Store clerks with no technical background who need exact button names and quick fixes when export fails.

### Common errors
- **Nothing happens after Export CSV**: the tablet is offline; connect to Wi-Fi and tap **Export CSV** again.
- **File is empty (0 bytes)**: no paid orders exist for that date; pick a different date.
- **Send to Email fails**: the store email is not set; ask the manager to add it under **Settings** > **Store Profile**.

## Facts
- App name: KoraPOS
- Supported devices: iPad or Android tablet
- Button labels: Reports, Daily Sales, Export CSV, Save to Files, Send to Email, Settings, Store Profile
- Date range limit: up to 90 days back
- Export wait time: up to 15 seconds
- Output filename format: `sales-YYYY-MM-DD.csv`
- Empty file size: 0 bytes
