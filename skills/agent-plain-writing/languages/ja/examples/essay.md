## Bad → Good

### 1. 目的を説明する書き出し

**Bad:** この記事を書いたのは、上京して一人暮らしを始めたときの寂しさを振り返るためだ。
**Good:** 青いスーツケースが部屋の隅に置かれたままになっている。壊れたファスナーには、母が結んだ荷造り用のひもがついていた。
**Fault:** 書いた目的を説明するメタな書き出しになっている。
**Fix:** 場面の中の具体的な物から直接始める。

### 2. 感情をそのまま名指す

**Bad:** 誰もいない駅のホームに立ち、私は言葉にできない孤独と不安を感じた。
**Good:** ホームのベンチは二つとも空いていた。ぬるくなったペットボトルの茶を握りしめると、結露した水滴が指の間を伝い落ちた。
**Fault:** 「孤独」「不安」と感情を直接書き、行動や細部がない。
**Fix:** 目に見える動きと触覚の細部に置き換える。

### 3. 教訓で閉じる終わり方

**Bad:** 学んだこと：過去を手放してこそ、新しい一歩を踏み出すことができる。
**Good:** ファスナーからひもをほどき、丸めて机の引き出しに入れた。それから雨の匂いがする窓を大きく開けた。
**Fault:** `学んだこと：` のラベルを付け、意味を説教している。
**Fix:** 一つの行動か情景で閉じ、解釈は読み手に委ねる。

### 4. 根拠のない評価形容詞

**Bad:** 家族全員で囲んだその朝の食卓は、本当に素晴らしくて忘れられない時間だった。
**Good:** 朝七時、テーブルの真ん中で味噌汁の湯気が立っていた。父は自分の箸をつける前に、焼き魚の腹の部分を私の小皿へ移した。
**Fault:** 「素晴らしい」「忘れられない」と評価の言葉だけで済ませている。
**Fix:** その場で見えた動きと湯気のような感覚の細部を書く。

## 完成サンプル (`essay`)

```markdown
青いスーツケースが部屋の隅に置かれたままになっている。壊れたファスナーには、家を出る朝に母が結んだ荷造り用のひもがついていた。九月の雨が雨戸の隙間から吹き込み、新しい畳の縁をわずかに濡らした。私はベッドの端に腰を下ろし、路地を走る原付のタイヤが水を跳ねる音を聞いていた。

夜行バスに乗る三日前、父は古い卓上扇風機を修理して段ボール箱に詰めた。学費の話は一切せず、モーターが熱くなったらヒューズを替えるようにとだけ言った。バスが動き出したとき、乗り場の柵の向こうで油のついた雑巾を握ったまま立つ父の姿が見えた。

今日の午後、部屋の中に響くのは流しの蛇口から落ちる水滴の音だけだった。段ボールを開け、扇風機のプラグを壁のコンセントに差し込む。羽根は二度ゆっくり回ってから一定の速さになり、埃と機械油の混じった匂いを狭い床へ押し出した。

私はスーツケースからひもをほどいて引き出しにしまい、雨の匂いがする窓を大きく開けた。
```
