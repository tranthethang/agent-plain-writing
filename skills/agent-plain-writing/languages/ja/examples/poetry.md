# 日本語の例: 詩

## 避けたい決まり文句

「胸が締めつけられる」「涙があふれる」「心の奥」「永遠に」「想いが募る」「心が震える」「儚い」「切ない」。意図して1回だけなら使ってよい。

## 形式

- **自由詩**(標準)。音数の決まりはない。息継ぎの位置で改行する。
- **俳句**(5-7-5)。具体的な物を1つ置く。季語は使ってもよい。
- 音数は**拍(モーラ)**で数える。拗音(ゃ・ゅ・ょ)は前の仮名と合わせて1拍。促音(っ)、撥音(ん)、長音(ー)はそれぞれ1拍。
- 俳句を書くときは、音数を必ず手で数え直す。スクリプトは音数を検査しない。

## Bad → Good

### 1. 感情の名前を書く → 物を置く

**Bad:**
想いが募る静かな夜に
心が震えて涙があふれた

**Good:**
夜、湯のみを二つ出して
一つ、棚に戻した

### 2. 愛情の宣言 → 細部

**Bad:** 母の愛は海よりも深く、山よりも高い。
**Good:**
母が編んだセーター
もう袖が短い
それでも脱げない

### 3. 一般論

**Bad:** 人生は長く険しい旅路である。
**Good:**
かかとのすり減った靴で
また坂を上る

### 4. 教訓で終わる

**Bad:**
花は散る
惜しむ心を
今を大切に生きよう

**Good:**
花は散る
拾う人はいない
朝、ほうきが通る

### 5. 決まり文句

**Bad:** 胸が締めつけられるほど、あなたが恋しい。
**Good:**
あなたの傘が
まだ玄関に立っている

### 6. 俳句

**Bad:** 春が来て 心うきうき 嬉しいな
(はるがきて / こころうきうき / うれしいな = 5-7-5 だが、気持ちを説明しているだけ)
**Good:** コンビニの 灯りに集う 夜の虫
(こんびにの = 5 / あかりにつどう = 7 / よるのむし = 5)
