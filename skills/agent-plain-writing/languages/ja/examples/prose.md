# 日本語の例: 散文(常体: だ・た)

## 避けたい決まり文句

「胸が高鳴る」「時が止まる」「言葉にできない」「心が張り裂ける」「瞳が輝く」「頬を伝う涙」「えも言われぬ」「言いようのない不安」。

## Bad → Good

### 1. 感情をそのまま書く → 行動

**Bad:** 彼女はその知らせを聞いて、とても悲しくなった。
**Good:** 彼女は箸を置いた。茶碗のご飯は手つかずのまま、湯気だけが消えた。

### 2. 決まり文句

**Bad:** 時が止まったように感じ、彼の胸は高鳴った。
**Good:** 壁の時計の音がやけに大きく聞こえた。一年ものあいだ、気づきもしなかった音だ。

### 3. 抽象的な風景 → 感覚

**Bad:** 田舎の朝は穏やかで、とても美しかった。
**Good:** 朝の庭には、まだ霜が残っていた。路地の向こうで誰かが玄関先を掃く。竹ぼうきの音が長く尾を引いた。

### 4. 形容詞で人物を書く

**Bad:** 祖父は優しくて、孫を大切にする人だった。
**Good:** 祖父は、いちばん大きな柿を末の孫に渡し、自分は柿が嫌いだと言った。

### 5. 説明する台詞

**Bad:** 「あなたが私の誕生日を忘れたから怒っているの」と、彼は悲しそうな声で言った。
**Good:** 「今夜は先に食べていいよ」
彼は背を向け、テレビをつけた。音量は上げなかった。

### 6. 長い1文 → リズム

**Bad:** 古びたバスが、曲がりくねった田舎道を、両側に青々とした田んぼが地平線まで広がる中、ゆっくりと走っていくので、乗客はみなとても穏やかな気持ちになった。
**Good:** バスはゆっくり走った。曲がりくねった田舎道の両側に、青い田んぼが地平線まで続く。居眠りをする人がいた。

### 7. 意味を説明して終わる

**Bad:** 彼は、家族こそが人生で最も大切なものだと気づいた。
**Good:** 彼は実家に電話をかけた。呼び出し音が三度鳴って、母が出た。

### 8. 無理のある比喩

**Bad:** 悲しみは大海のように彼女の心を包み込んだ。
**Good:** 彼女は同じコップを三度洗った。

## 完成見本(約150字)

```
母は夕方から、私の部屋の前に立っていた。戸の下の隙間に影が落ちていて、少しも動かない。
私は開けなかった。

母は二度、小さく戸を叩いた。それから、皮をむいたみかんを皿にのせて、廊下に置いた。
スリッパの音が遠ざかっていく。
夜になってから戸を開けた。みかんは縁が茶色くなっていたが、全部食べた。
```

注: 「私は怒っていた」「母は私を思っていた」という文は1つもない。気持ちは、皿のみかんの中にある。
