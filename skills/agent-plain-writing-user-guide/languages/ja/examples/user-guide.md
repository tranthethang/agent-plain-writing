# 日本語の例: ユーザーガイド(です・ます調)

## 専門用語の言い換え

| 専門用語 | ユーザーにはこう言う |
|---|---|
| キャッシュ | 一時的に保存したデータ |
| トークン | ログイン情報 |
| APIキー | 接続用のコード |
| 同期 | どの端末でも同じ内容に自動で更新されること |
| 認証 | ログインして本人を確認すること |
| 二段階認証 | スマートフォンに届くコードによる、追加の確認 |
| セッションの有効期限切れ | もう一度ログインするよう求められること |
| バックアップ | 予備のコピー |
| リストア | 予備のコピーから元に戻すこと |
| 設定(構成) | 設定 |
| ファームウェア | 機器の中のソフトウェア |
| サーバー | (不要なら書かない) |
| ログ | 操作の履歴 |

画面に**表示される言葉**(例: 「トークン」というボタン)は、その言葉のまま使い、1度だけ説明する。

## Bad → Good

### 1. 1つの手順に動作が多すぎる

**Bad:** 設定画面にアクセスし、アカウントの項目を探して、パスワードの変更を行ってください。
**Good:**
1. **設定**をタップします。
2. **アカウント**を選びます。
3. **パスワードを変更**をタップします。
4. 現在のパスワード、新しいパスワードの順に入力します。
5. **保存**をタップします。「パスワードを変更しました」と表示されます。

### 2. 仕組み → 結果

**Bad:** 本アプリはバックグラウンド同期の仕組みにより、クラウドサーバーを介して端末間のデータを自動的に更新します。
**Good:** スマートフォンで編集すると、パソコンの内容も自動で更新されます。操作は必要ありません。

### 3. 専門用語

**Bad:** トークンの有効期限が切れた場合は、再認証を行ってください。
**Good:** ログインの有効期限が切れたと表示されたら、もう一度ログインしてください。

### 4. 警告

**Bad:** データを削除した場合、状況によっては復元できない可能性がありますのでご注意ください。
**Good:** **注意:** 削除したデータは、元に戻せません。

### 5. エラー対応

**Bad:** エラーが発生した場合は、ネットワーク接続をご確認いただくか、サポート窓口までお問い合わせください。
**Good:**

| 表示 | 対処 |
|---|---|
| 「接続できません」 | Wi-Fiを確認して、もう一度試します。 |
| 何度試しても直らない | 画面のスクリーンショットを撮り、[サポート窓口]に送ります。 |

### 6. 形容詞で機能を説明する

**Bad:** レポート機能は、多様なオプションを提供し、データを包括的に分析できます。
**Good:** **レポート**で、今月の売上を確認できます。

### 7. 仕組みを全部説明してしまう(よくある失敗)

**Bad:** 送信ボタンを押すと、リクエストはキューに追加されます。バックグラウンドのプロセスがそれを取り出し、データを検証してデータベースに書き込みます。その後、結果がメールで通知されます。
**Good:** **送信**をタップします。数分後に、結果がメールで届きます。
**規則:** 「ユーザーはなぜこれを知る必要があるか」と問う。理由がなければ消す。

### 8. ボタン名の誤り

**Bad:** 確定ボタンを押して変更を保存してください。
**Good:** **保存**をタップします。

### 9. 前提条件

**Bad:** 操作の前に、必要な権限が付与されていることをご確認いただく必要があります。
**Good:** **管理者**である必要があります。**追加**ボタンが見つからない場合は、管理者に権限を依頼してください。

### 10. 目的

**Bad:** 本ガイドは、レポートのエクスポート機能をご利用いただくために必要な情報を提供することを目的としています。
**Good:** このガイドでは、レポートをExcelファイルに書き出す方法を説明します。

## 完成見本

```markdown
# パスワードを変更する

パスワードを忘れたとき、または新しくしたいときに使います。

## 始める前に
- ログインしていること。
- 現在のパスワードを覚えていること。

## 手順
1. **設定**をタップします。
2. **アカウント**を選びます。
3. **パスワードを変更**をタップします。
4. 現在のパスワードを入力し、新しいパスワードを2回入力します。
5. **保存**をタップします。「パスワードを変更しました」と表示されます。

## うまくいかないとき

| 表示されるメッセージ | 対処 |
|---|---|
| 「現在のパスワードが違います」 | もう一度入力します。忘れた場合は、ログイン画面の**パスワードを忘れた方**をタップします。 |
| 「パスワードが短すぎます」 | 8文字以上にします。 |
```
